## Zadrinth Launcher 0.1.0-beta: primeira prévia

Primeira versão de teste do **Zadrinth Launcher**, um launcher de Minecraft: Java Edition para Android inspirado no Modrinth App e baseado no Zalith Launcher 2.

### Novidades
- Visual novo: tema escuro com degradê azul → violeta → rosa
- Barra lateral fixa: Início, Explorar, Biblioteca, Criar instância, Contas e Configurações
- **Biblioteca** de instâncias em grade, com busca, filtros e botão **Jogar**
- Ícone novo em pixel art

### Qual APK baixar?
| Arquivo | Para quem |
|---|---|
| `ZadrinthLauncher-0.1.0-beta-arm64.apk` | **A maioria dos celulares** (64 bits) |
| `ZadrinthLauncher-0.1.0-beta-arm.apk` | Celulares antigos de 32 bits |
| `ZadrinthLauncher-0.1.0-beta.apk` | Funciona em qualquer aparelho, mas é bem maior |
| `-x86` / `-x86_64` | Emuladores e alguns tablets/PCs |

### Limitações desta prévia
- O login com **conta Microsoft** ainda depende da aprovação do app pela Microsoft/Mojang. Até lá, use uma conta local (offline).
- A tela **Explorar** ainda é a do Zalith. A versão no estilo Modrinth vem nas próximas etapas.
- O tempo jogado ainda não é contado.
- Downloads do CurseForge precisam de uma chave da API que ainda não foi configurada. O Modrinth funciona normalmente.

### Aviso
Esta é uma **versão modificada não oficial** do [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2). O projeto não tem ligação com a Modrinth, a Mojang ou a Microsoft. Código aberto sob a licença GPL-3.0.
