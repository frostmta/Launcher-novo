## Zadrinth Client 0.5.0-beta: primeiros mods de PvP dentro do jogo

Chegou o **mod do Zadrinth Client** para o **Minecraft 1.8.9**. O launcher instala sozinho em toda instância **1.8.9 com Legacy Fabric**.

### Novidades no jogo
- **Menu do Zadrinth (Right Shift):** cartões de mods com ATIVADO/DESATIVADO e o botão **Editar HUD**
- **ToggleSprint:** um toque na tecla de correr liga a corrida contínua; outro toque desliga. Mostra **[Sprinting (Toggled)]** na tela
- **ToggleSneak:** o mesmo para agachar (vem desligado)
- **Editor de HUD:** arraste o status para onde quiser; clique direito muda o tamanho
- **Ícone no TAB:** o cristal do Zadrinth aparece ao lado do seu nome e do nome de quem também usa o client no mesmo servidor

### Como usar
1. Crie uma instância **1.8.9** com **Legacy Fabric** (Explorar → Jogo → 1.8.9 → Legacy Fabric)
2. Jogue normalmente: o mod é colocado na pasta mods sozinho
3. Para abrir o menu no celular, crie um botão nos controles da tela com a tecla **Right Shift** (com teclado físico, é só apertar)

O arquivo `zadrinth-client-0.1.0.jar` também vem anexado aqui, para quem quiser instalar em outro launcher.
